## A. 現状棚卸し（Claudeがコードから読み取ったもの）

### 画面構成（大人用 gas-app.html / 4416行・444KB）
| 下タブ | 中身 |
|---|---|
| ホーム | 直近大会ヒーローカード（あとN日）／未集金合計・予定件数の統計／今週の予定 |
| 大会 | サブタブ3つ＝一覧・進捗・結果。一覧には「開催予定/過去」切替＋タイプ（単発/予選/決勝）＋ステータスの2つのプルダウン＋検索トグル＋「今日のタスク」 |
| 会計 | サブタブ2つ＝大会会計（フィルター付きカード）・おでかけ（記録一覧/精算） |
| カレンダー | 月グリッド＋日別シート |
| ＋FAB | 新規大会登録 |
| 詳細オーバーレイ | セクション積み（基本・エントリー・音源・動画・写真・費用・資料）＋編集＋進捗更新ボトムシート |

### 提出物・支払いの「形が揃っていない」実態
| 種別 | 持っている項目 |
|---|---|
| エントリー | 状況・期限・開始日・開始時間 |
| 音源 | 要否（事前/当日/不要）・期限・備考・状況・当日CD・予備データ・家族別持参×3 |
| 動画 | 要否・期限・URL・状況 |
| 写真 | 要否・期限・URL・状況 |
| エントリー費 | 金額・支払方法・期限・振込済・家族別支払済×3 |
| 観覧費 | 大人単価・子供単価・付き添い無料・支払方法・期限・振込済・家族別（大人数/子供数/支払済）×3 |
| 交通費／その他 | 金額・家族別対象/支払済 |
| 衣装 | メモのみ |
| 資料 | ラベル＋URL×5 |

→ 「要否／期限／状況／証跡」の4点セットに正規化できる余地が大きい。

### 自動ステータス
エントリー予定 → 準備中 → 当日待ち → 会計待ち → 完了（＋キャンセル）

### 技術面の重さの原因（推定）
- 1ファイル444KBのHTMLをGASが配信、`google.script.run`で全データ取得
- GAS特有のオープニング待ち・警告バナー・Safari UI露出（API化で根本解決可）
- 子供用（ramuse-kid・3893行）は別HTMLをGitHub Pages配信＝二重保守
